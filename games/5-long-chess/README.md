# Long Chess

> **Note:** This README was auto-generated by AI as a project summary.

Browser-only 10x10 chess variant (100 squares). No build, no dependencies,
no backend — two static files.

## What it does
Capture race: each side starts with 10 rooks + 10 pawns. The side that runs
out of legal moves loses. Pawns promote to crowns (rook + one step any
direction) when they capture.

## Key Files
- `engine.js` — pure game logic + negamax AI (UMD; Node-testable)
- `index.html` — UI: board, move hints, undo, side/difficulty pick, autoplay
- `tests/engine.test.mjs` — Node headless suite (`nix-shell -p nodejs --run "node tests/engine.test.mjs"`)

## Deploy
Served static at `https://jev-chess.tgr.rs/long-chess/` via Caddy path under
the jev-chess gateway (no backend). See `web/5-jev-chess-proxy/`.
