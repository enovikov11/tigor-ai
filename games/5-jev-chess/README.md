# 5-jev-chess

> **Note:** This README was auto-generated by AI as a project summary.

## What it does

Single-file static chess app: play standard chess against TypeSafe (Jev) used as a
constrained move selector. chess.js is the sole source of truth for rules/state;
gchessboard is the view layer. Every AI turn sends all legal moves as one TypeSafe
Choice; only a returned LAN already declared legal is ever applied. No engine,
no backend, no build step.

## Key Files
- `index.html` — the whole app (HTML+CSS+JS, CDN ES modules)

## Play
- Open `index.html` on any static HTTP/HTTPS host. Paste a TypeSafe API key
  (kept in memory only, never persisted), pick White/Black/Random, New Game.
- Serve from an origin whitelisted in your TypeSafe account, or cross-origin
  calls are blocked by CORS (the app detects and reports this).

## Notes
- Pinned deps: `chess.js@1.4.0`, `gchessboard@1.4.0` (jsDelivr ESM).
- Supports castling, en passant, Q/R/B/N promotion chooser, checkmate/stalemate/
  repetition/50-move/insufficient-material detection, clickable history review,
  AI decision inspector (confidence, model, tokens, top-5 candidates).
- API: `POST https://api.typesafe.ai/v1/systemone`, model `jev-latest` (editable).
